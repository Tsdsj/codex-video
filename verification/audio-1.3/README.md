# 原创音效包 1.3 验证

2026-10-01，新制四组共 24 个音效。Python 标准库程序合成，无第三方采样、无模型、无 API。素材在插件 assets/original-audio，生成器在 scripts/build_sound_pack.py。

## 已验证

- 24 个 WAV：48 kHz、16-bit、双声道，时长与目录一致，锚点在合法范围，首尾采样为零。
- 所有文件哈希不同；独立第二次生成与首次文件逐字节一致，限本机环境。
- 全部 FFmpeg 解码成功；真峰值范围约 -8.99 至 -5.88 dBTP，低于 -3 dBTP 验证阈值。
- 单声道折叠后的 RMS 能量比例大于 0.65，无严重相位抵消。
- 试听页的 24 个单音效与 4 个串听播放器均成功加载；新播放器开始时会暂停其他播放器。
- 原创音效演示：将 silk-swipe、cushioned-land、reveal-spark 接入既有 8 秒画面，新文件 original-sounds-demo.mp4 已编码及完整解码，原视频未覆盖。

短于响度积分窗口的素材可能得到 LUFS=-inf，不代表音频静音；已用实际 PCM 峰值与非零内容验证。不能通过给极短声音强行增益来追求 LUFS 目标。

## 边界

没有实际听音证据，音色满意度、具体画面的感知同步和主观高级感待试听。材质包是风格化合成，不声称真实木头/陶瓷/玻璃/金属录音。24 个声音覆盖设计用途，不能代替完整拟音库或配乐库。

## 证据

- verify_pack.py：格式、非静音、锚点、端点、单声道、唯一性检查。
- technical.json：逐素材真峰值、完整解码、重复生成一致性。
- browser.json：浏览器音频元数据和互斥播放。
- demo-cues.json、demo-mix/report.json：演示事件对齐与混音。
- repro/：第二次生成的证据；不进入插件包。

验证脚本中的 Playwright / FFmpeg 环境复用本机已有工具，不写入可分发插件。
