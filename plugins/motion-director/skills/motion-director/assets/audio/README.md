# 免费本地音效候选

8 个 Kenney Interface Sounds 文件，CC0-1.0。来源 https://kenney.nl/assets/interface-sounds ，下载日期 2026-10-01。原始包许可见 KENNEY-LICENSE.txt；文件未改写，哈希与技术指标见 catalog.json。

这些是按用途与技术检查挑选的候选，尚未实际试听，不代表它们一定适合精致产品片。最大峰值标记是估算锚点，实际使用要校正感知起音。部分有损音频解码峰值可能超过 0 dBFS，应在浮点域衰减后混合。

将本目录复制到作品中，编辑 example-cues.json，再用技能 scripts/mix_audio.py 输出到新的目录。样例默认 8 秒 / 60 fps，包含移动、到位、确认三处提示；并非通用配音设计。
