# 把“高级感”变成可检查的决定

这些是设计判断工具，不是唯一风格。先沿用品牌与确认的设计，再判断运动是否加强了信息。用户没有选风格时，提供适量关键画面供确认，不把模板配色当品牌。

## 构图先于运动

先截取每镜的稳定状态，检查主视觉、对齐、负空间、文字比例、材质和光源。静止画面混乱，动画通常会放大问题。

每镜写一句“观众先看到什么、接着理解什么”。主次靠大小、对比、位置及进入时间共同区分；不是每层都需要动，也不是每镜都需要相机。

正文和品牌名必须有可读的稳定区间。按真实文字长度检查停留，先以正常速度看一遍，不能凭固定 0.5 秒就认为足够。

## 运动契约

实现前为重要对象写清：起始状态 → 触发原因 → 路径/速度峰值 → 接触或到达 → 稳定状态 → 下一镜如何接管。

转场优先由内容关系产生：同一物体展开为信息面板、主视觉占据画面形成遮挡切换、细节承接全景。只有场景关系需要时再使用 wipe、slide 或 dissolve，不给每个切点随机选特效。

错相用来表达因果或层次：主物体先到位，标签随后解释，环境反馈跟随事件。错相量应与 fps、运动速度和镜头时长一起调，不照抄“晚几帧”。真实附着元素、接触阴影等仍保持一致关系。

## 常见问题与修正

| 现象 | 更可能的问题 | 优先修正 |
|---|---|---|
| 看起来像 PPT | 所有元素同步淡入、镜头间没有承接 | 给主事件独立时间结构，保留一个跨镜头主体 |
| 到处都在弹 | 每个属性都套默认 spring | 文字/相机先改为克制缓动，仅受力物体保留弹性 |
| 很忙但没信息 | 动效、背景、文字同权重 | 删除无表达作用的运动，延长主信息的稳定停留 |
| 动作发飘 | 匀速滑动、接触无反馈或物体无支撑 | 明确受力与速度变化，修正接触/遮挡/阴影 |
| 转场廉价 | 每镜重置、无意义推拉缩放 | 建立形状、方向或内容的连续关系 |
| 画面“脏” | 过多 bloom、纹理、模糊或半透明叠层 | 先恢复清晰轮廓、对比和一致光照 |
| 卡顿或闪烁 | 不确定性、加载未就绪、像素级跳变 | 先查帧状态与加载屏障，再查编码/性能 |

## 有限迭代

每轮列出影响最大的具体问题，附时间码和画面证据；一次改清楚原因相关的参数。先修可读性、节奏、连续性，再精修光影和声音。

“高级感通过”不能由脚本打分自动宣布。交付时说明哪些帧检查过、是否看过正常速度、是否实际听音，并保留用户审美判断。模板与测试只能提高稳定性，不能代替作品评价。
