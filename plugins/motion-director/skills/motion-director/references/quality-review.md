# 动效视频验收

用“通过 / 失败 / 不适用 / 未验证”记录真实结果；工具、时间码和产物路径作为证据。不要以主观分数代替问题定位。

| 维度 | 要检查的内容 | 合适的证据 |
|---|---|---|
| 技术 | 分辨率、fps、总帧数/时长、编码、音轨符合 Brief；完整解码无错误 | 媒体探测结果、解码日志 |
| 信息 | 字体正确、没有溢出截断、品牌和文案准确、阅读停留足够 | 实际画面和正常速度播放 |
| 注意力 | 每镜主要信息明确、主次运动协调、装饰不过度抢视线 | 关键帧与整片回放 |
| 运动 | 交接连续、形变有依据、回稳自然；无非预期抖动、跳变、穿模 | 接触/转场邻域的逐帧图与播放 |
| 光影 | 光源和材质内部一致；接触影与物体位置匹配 | 接触前后帧 |
| 节奏 | 动作、停顿和段落服务表达；不是所有层同步出入 | 正常速度及必要的慢速播放 |
| 声音 | 瞬态对接触、旁白清晰、无突断或失真、首尾合适 | 实际听音加波形/峰值检查 |
| 复现 | 保存源工程、素材来源、锁定依赖、种子和实际命令 | 可重跑工程与输出记录 |

## 抽帧策略

检查第 0 帧、最后有效帧 `N-1`；每个切点与接触点检查邻近帧；补查最大速度、最大形变、回稳和文字完整显现。低帧率或短动作需要更密采样。均匀抽帧容易漏掉单帧闪烁，不能作为唯一证据。

HTML 图集若展示实际帧序列，可按帧号检视。若展示的是视频元素的近似 seek，应标明近似，不声称逐帧精确。
