# tt-blog · 信号，在线。

状态：设计提案 v1，待用户确认；不是成片。日期：2026-10-01。

## 导演 Brief

面向第一次认识 tt 的技术读者、开发者与潜在协作者，用于网站、B站和桌面分享。画幅已确认：16:9。建议制作规格：1920 × 1080、30 fps、15 秒、450 帧；本轮关键画面按 1600 × 900 输出，同为 16:9。

希望观众记住：这是一个把想法做成作品、也记录制作过程的个人博客；访问 www.ttlist.top。

方向：「信号，在线」。沿用网站 Signal 的 #09090B、#EDEDEF、#7CFFB2、可见网格、通道编号及 tt_ 字标；绿只强调视线落点，保持背景稳定。叙事从“做”进入“写”，避免把个人博客表现成只有作品的展柜。

比较过的方向：
- **作品 + 记录（本案）**：真实内容支撑品牌，兼顾访问动机与视觉表现。
- 页面漫游：最直观，但 15 秒内容易碎，整页文字太小。
- 纯品牌字卡：制作简洁，但缺少作品与文章证据。

主标题顺序承接“作品 → 城市 → 细节 → 记录”，每镜只有一个主信息。固定 tt_、通道标签与底栏提供方向感，不参与抢眼动画。镜头二、三的图像可微动，文字固定；镜头四停止图像运动，给阅读让位。

## 运动与声音设计（仅方案）

不使用弹跳、随机故障闪烁和连续 whoosh。位置变化采用缓入缓出的单次移动，图像微推线性且幅度受限。点阵展开只出现在开场承接，片尾背景静止。站点截图中的时间、状态读数不作为实时性能或在线可靠性声明。

默认无旁白，静音观看成立。若制作有声版，建议稀疏电子氛围与轻脉冲，不强行按固定 BPM 切镜；素材尚未选择，未采购、未混音。

| 声音建议 | 起始 / 瞬态 / 结束帧 | 作用与建议电平 |
|---|---|---|
| 短促信号音 | 6 / 12 / 26 | 配合标题显现，峰值约 -16 dBFS |
| 低频氛围层 | 0 / 无瞬态 / 450 | 仅支撑气氛，约 -28 dBFS，f420 起淡出 |
| 轻微机械触点 | 183 / 189 / 204 | 窗口就位，峰值约 -22 dBFS |
| 柔和确认音 | 366 / 378 / 410 | 网址稳定，峰值约 -20 dBFS |

以上是事件设计与初始电平建议，不能视为已验证响度。优先使用可本地合成的基础音色，避免新增付费服务；正式成片时再检查许可、响度和声画同步。
